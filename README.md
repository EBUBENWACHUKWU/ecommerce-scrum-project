# E-Commerce-scrum-project
## Overview

This project demonstrates the application of Scrum principles and Agile project management practices in the development of an E-Commerce Website.

## Role

Scrum Master

## Project Goal

Develop an e-commerce platform that allows customers to:

- Create accounts
- Log in securely
- Browse products
- Add products to cart
- Complete purchases
